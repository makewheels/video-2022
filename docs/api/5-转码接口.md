## 接口详情

### 阿里云转码回调

阿里云云函数ffmpeg转码完成后的回调接口。转码服务在完成视频转码后，调用此接口通知后端更新转码状态。

**请求**
```
POST /transcode/aliyunCloudFunctionTranscodeCallback
Content-Type: application/json
```

**请求体**

由阿里云转码服务发送的JSON回调数据，包含转码任务的执行结果。

**转码流程说明**

1. 后端调用阿里云云函数发起转码任务
2. 云函数使用ffmpeg进行视频转码（切片为HLS TS格式）
3. 转码完成后，云函数回调此接口通知结果
4. 后端更新视频状态为READY

**相关的阿里云云函数接口**（由后端内部调用，非对外接口）

- ffprobe获取视频信息：`POST https://ffprobe-video-transcode-{id}.cn-beijing.fcapp.run`
- 发起转码：`POST https://transcode-master-video-transcode-{id}.cn-beijing.fcapp.run`

**转码请求示例**
```json
{
    "outputDir": "videos/{userId}/{videoId}/transcode/720p",
    "videoId": "62626cff1fb6c600b2a7f14d",
    "audioCodec": "aac",
    "resolution": "720p",
    "quality": "keep",
    "bucket": "video-2022-prod",
    "jobId": "829bb555d5b14123ad3cf129519701de",
    "endpoint": "oss-cn-beijing-internal.aliyuncs.com",
    "width": 1280,
    "height": 720,
    "videoCodec": "h264",
    "callbackUrl": "https://videoplus.top/transcode/aliyunCloudFunctionTranscodeCallback",
    "inputKey": "videos/{userId}/{videoId}/raw/{fileId}.mp4",
    "transcodeId": "62626d7e1fb6c600b2a7f14e"
}
```

## 本地转码接口（LOCAL）

用于「客户端用本机 FFmpeg 转码后回传」的零云转码成本通道。前提：创建视频时 `transcodeMode = LOCAL`（见[上传视频接口](2-上传视频接口.md)），此时服务端不会发起 MPS / 云函数转码与截帧。

完整流程：`createTranscode` 登记一档分辨率并拿到 OSS 上传凭证 → 客户端用本机 ffmpeg 切 HLS（m3u8 + ts）直传到 `outputDir` → `finishTranscode` 触发服务端扫描 OSS 登记 ts、置视频就绪。封面同理走 `createCover` / `finishCover`。所有接口都需登录态（`token`），且校验视频归属当前用户。

### 本地转码-登记一档

```
POST /transcode/local/createTranscode
Content-Type: application/json
```

**请求体**

| 字段 | 类型 | 说明 |
|------|------|------|
| videoId | String | 视频 ID |
| resolution | String | 目标分辨率：480p / 720p / 1080p |
| width / height | Integer | 源片宽高（首次调用写入 `Video.mediaInfo`，多档幂等） |
| durationMs | Long | 源片时长（毫秒，**必填**，回调时算码率用） |
| videoCodec / audioCodec | String | 源片编码，如 h264 / aac（无音频可空） |
| bitrate | Integer | 源片整体码率（kbps，与 MPS 口径一致） |

**响应 data**

| 字段 | 说明 |
|------|------|
| transcodeId | 转码任务 ID |
| resolution | 目标分辨率 |
| m3u8Key | m3u8 在 OSS 的目标 key |
| outputDir | m3u8/ts 上传目录（m3u8Key 的父目录） |
| tsFilenameTemplate | ts 命名约定 `{transcodeId}-%05d.ts`，与 MPS 输出一致 |
| uploadCredentials | OSS STS 上传凭证（bucket/endpoint/accessKeyId/secretKey/sessionToken） |

> 约束：m3u8 必须以**相对文件名**引用 ts（FFmpeg `-f hls` 默认行为），且 m3u8 + ts 必须上传到 `outputDir` 下，回调才能正确扫描登记。

### 本地转码-完成回传

```
POST /transcode/local/finishTranscode?transcodeId={transcodeId}
```

客户端把该档的 m3u8 + ts 全部传到 `outputDir` 后调用。服务端把 Transcode 置为 `FINISHED`，并复用 `TranscodeCallbackService.onTranscodeFinish` 扫描 OSS 登记 ts、计算码率；当该视频所有分辨率都完成时置 `READY`。

### 本地封面-登记

```
POST /cover/local/createCover
Content-Type: application/json
```

**请求体**：`{ "videoId": "...", "extension": "jpg" }`（extension 可空，默认 jpg）

**响应 data**：`{ coverId, coverKey, uploadCredentials }`。客户端把本机截好的封面图直传到 `coverKey`。

### 本地封面-完成回传

```
POST /cover/local/finishCover?coverId={coverId}
```

封面图上传完成后调用，服务端置封面 `READY` 并把 `coverId` 挂到视频上。

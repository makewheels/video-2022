## 接口列表

### 订阅读取迁移契约（S15.b.1）

`GET /subscription/getStatus?channelUserId=...` 返回当前用户是否订阅的 Boolean；`GET /subscription/getMySubscriptions?skip=0&limit=20` 返回频道ID数组，按订阅createTime降序，保留重复、null与失效引用。两路由都必须登录，缺失/坏token实际返回HTTP401；缺失参数或非法整数沿旧HTTP200/code1。正limit最大50，零/负limit不限条数，负skip按0处理。

Python仅在显式`subscription_reads=True`隔离装配启用，默认及生产入口不变；不包含subscribe/unsubscribe写入。实际旧Java/独立Mongo26组样本与Python逐项对照，详见[验收与回退](../requirements/2026-10-14-serverless-backend/user/subscription-reads.md)，真实FC与实机未跑。

### 订阅写入及通知迁移契约（M030–M032）

`GET /subscription/subscribe`和`GET /subscription/unsubscribe`仍以`channelUserId`查询参数操作，必须登录；保留原直接错误、记录与独立计数的写入顺序和部分失败，不新增通知。Python仅在显式`subscription_writes=True`安装，已有`subscription_reads`不隐式启用写入。

通知四路由的实际身份策略是页首历史认证概括的例外：旧`InterceptorConfiguration`未给`/notification/**`安装CheckToken，缺失/坏token按原`userId=null`查询/窄写，不在迁移中新增401或非空ID校验。`GET /notification/getMyNotifications`、`GET /notification/getUnreadCount`由`notification_reads=True`安装；`POST /notification/markAsRead`、`POST /notification/markAllAsRead`由`notification_writes=True`安装，读写开关独立、默认关闭。

通知列表默认page=0/pageSize=20，正pageSize最大50，保留非正大小、整数边界、UTC毫秒日期及旧BSON错误；已读按原所有者条件仅更新read，全部已读不解析正文。真实旧HTTP/完整BSON、JSON绑定和回退边界见[订阅与通知契约](../requirements/2026-10-14-serverless-backend/user/subscription-notifications.md)。仅隔离能力，生产入口和各端用法不变。

| 接口 | 方法 | 路径 | 认证 |
|------|------|------|------|
| 请求验证码 | GET | /user/requestVerificationCode | 不需要 |
| 提交验证码 | GET | /user/submitVerificationCode | 不需要 |
| 通过token获取用户 | GET | /user/getUserByToken | 不需要 |
| 通过ID获取用户 | GET | /user/getUserById | 不需要 |

## 接口详情

### 请求验证码

当前实现将验证码保存到 MongoDB `verification_codes`，phone 唯一索引、createdAt 的 TTL 索引为 600s。已有记录时复用、不更新时间；此方法没有调用短信 SDK。提交按记录是否仍存在判断过期，未另行校验精确年龄。源码核对及待动态验证边界见 [登录契约台账](../requirements/2026-10-14-serverless-backend/user/login-contract.md)。

**请求**
```
GET /user/requestVerificationCode?phone={phone}
```

**参数**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | 是 | 手机号 |

**响应示例**
```json
{
    "code": 0,
    "message": "成功",
    "data": null
}
```

---

### 提交验证码

验证短信验证码，验证成功返回用户信息和token。

**请求**
```
GET /user/submitVerificationCode?phone={phone}&code={code}
```

**参数**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | 是 | 手机号 |
| code | String | 是 | 验证码 |

**响应示例（验证成功）**
```json
{
    "code": 0,
    "message": "成功",
    "data": {
        "id": "u_2507677900001740",
        "phone": "18812345678",
        "registerChannel": "WEB",
        "createTime": "2026-03-06T15:05:19.187Z",
        "token": "2029936368066678784"
    }
}
```

**响应示例（验证失败）**
```json
{
    "code": 1,
    "message": "fail",
    "data": null
}
```

| 字段 | 说明 |
|------|------|
| id | 用户ID |
| phone | 手机号 |
| registerChannel | 注册渠道：WEB / WECHAT_MINI_PROGRAM |
| createTime | 创建时间 |
| token | 登录凭证，用于后续认证接口 |

### 通过token获取用户

**请求**
```
GET /user/getUserByToken?token={token}
```

**参数**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| token | String | 是 | 登录凭证 |

**响应示例**
```json
{
    "code": 0,
    "data": {
        "id": "u_2507677900001740",
        "phone": "18812345678",
        "registerChannel": null,
        "createTime": "2026-03-06T15:05:19.187Z",
        "updateTime": "2026-03-06T15:05:19.187Z",
        "token": "2029936368066678784"
    },
    "message": "成功"
}
```

### 通过ID获取用户

**请求**
```
GET /user/getUserById?userId={userId}
```

**参数**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | String | 是 | 用户ID |

**响应示例**
```json
{
    "code": 0,
    "data": {
        "id": "u_2507677900001740",
        "phone": "18812345678",
        "registerChannel": null,
        "createTime": "2026-03-06T15:05:19.187Z",
        "updateTime": "2026-03-06T15:05:19.187Z",
        "token": null
    },
    "message": "成功"
}
```

> 注意：通过ID查询时，token字段不返回。

---

### 获取客户端ID

用户无需登录即可观看视频。clientId用于追踪未登录用户，前端保存在localStorage中。

**请求**
```
GET /client/requestClientId
```

**响应示例**
```json
{
    "code": 0,
    "data": {
        "clientId": "69aaf146e0df6537cc235392"
    },
    "message": "成功"
}
```

---

### 获取会话ID

用于区分观看次数，前端保存在sessionStorage中。

**请求**
```
GET /session/requestSessionId
```

**响应示例**
```json
{
    "code": 0,
    "data": {
        "sessionId": "69aaf146e0df6537cc235391"
    },
    "message": "成功"
}
```

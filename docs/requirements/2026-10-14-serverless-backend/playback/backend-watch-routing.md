# 统一隔离后端播放路由装配

目标：将已实现的观看信息、主/子清单接入显式 BackendApplication 工厂，复用同一个用户身份与日志生命周期。

工厂通过成对的 playback_signature_secret、internal_base_url 显式开启；未提供时保留原有路由集合，不默认读取环境或改变生产入口。单独提供任一参数、空配置立即失败，避免生成无效签名链接。复用现有 Mongo provider、封面签名端口和 RequestCycle，不额外解析身份或重复保存日志。

验收：真实回环随机 Mongo 库、ASGI 请求通过统一工厂完成私密观看信息→主→子清单；验证无 token 的后续签名请求、三条日志、拒绝与已有用户/搜索路由并存。未修改媒体业务算法，既有 Java 黄金契约继续回归。回退本 PR 即恢复独立播放工厂；无生产切流、文件下载、计费或可靠任务装配。

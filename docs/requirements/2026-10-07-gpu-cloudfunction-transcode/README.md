## 与业务后端迁移的区别

本需求负责视频处理CPU/GPU函数。另一个[Python/FC业务后端迁移](../2026-10-14-serverless-backend/overview/status.md)负责把现有Java业务逐域迁移，两者验收和上线状态分开记录。CI的Worker原型镜像只做编译/编码器枚举/导入验证，不能当作线上函数发布或真实GPU编码。
